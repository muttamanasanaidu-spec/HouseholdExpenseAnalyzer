# Household Expense Pattern Analyzer

## Project Description
The Household Expense Pattern Analyzer is a Python-based project that analyzes household expenditure patterns, summarizes spending, identifies unusual transactions, and forecasts future expenses.

## Objectives
- Analyze household expenses by category.
- Study monthly spending trends.
- Compare household income and expenses.
- Analyze spending by payment mode and day of the week.
- Identify potentially unusual transactions using the Z-score method.
- Forecast expenses for the next three months using Linear Regression.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Project Files
- `expense_analyzer.py` — Main Python program.
- `household_expenses.csv` — Sample transaction dataset.
- CSV result files — Cleaned data, summaries, and analysis results.
- PNG files — Visualizations and charts.

## How to Run
1. Install Python.
2. Install the required libraries:

   `python -m pip install pandas numpy matplotlib scikit-learn`

3. Run the program:

   `python expense_analyzer.py`

The program generates the sample dataset if it does not exist and saves analysis results and charts in the `outputs` directory.

## Note
The included dataset is simulated sample data for demonstration. Forecasts are estimates and may not represent actual future expenses.
